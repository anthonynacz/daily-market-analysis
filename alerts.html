GitHub access (this device only)

Saving writes the settings file to your repository, so this page needs a GitHub token. It is kept only in this browser's storage and sent only to api.github.com.
  1. Open GitHub → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → daily-market-analysis.
  3. Permissions → Repository → Contents: Read and write. Nothing else.
  4. Paste the token above and press Remember.
